{% load i18n %} {% comment %} Light/dark toggle. Writes a `theme` cookie rather than localStorage (CLAUDE.md §2 forbids localStorage/sessionStorage) — which also means the server can read it and stamp during the initial render, so a returning visitor never sees a flash of the wrong theme. Alpine flips the attribute in place for instant feedback; the cookie only matters on the next navigation. Three states, cycled in order: follow the OS -> light -> dark -> follow the OS. "Follow the OS" is the absence of the attribute, letting the prefers-color-scheme media query in static_src/input.css decide. {% endcomment %}
